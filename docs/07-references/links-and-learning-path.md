## Recommended Learning Path

### Day 1–2: Foundations
1. Read `01-project-plan/overview.md` — understand what we're building
2. Read `01-project-plan/architecture.md` — understand the three execution contexts
3. Read `04-win32com/reference.md` (Threading Model section) — understand WHY the architecture is the way it is

### Day 3–4: SAP Scripting Deep Dive
4. Read the SAP GUI Scripting API PDF (at least: Introduction, Object Model overview, GuiSession, GuiMainWindow, GuiGridView sections)
5. Read `02-sap-scripting/object-model.md` — the full object tree
6. Read `02-sap-scripting/key-objects.md` — the objects you'll use daily
7. Download and explore Scripting Tracker — connect it to a live SAP session

### Day 5: Python + SAP Practice
8. Read `02-sap-scripting/vbs-to-python.md` — conversion rules
9. Record a simple macro in SAP (e.g., open SE16, enter a table name, execute)
10. Convert the VBScript to Python and run it standalone
11. Try reading an ALV grid's data programmatically

### Day 6–7: NiceGUI
12. Read `03-nicegui/reference.md` — full framework overview
13. Build a minimal NiceGUI app with a button, a timer, and a table
14. Practice `run.io_bound` with a simulated blocking call
15. Build a page with `ui.tree` and `ui.aggrid`

### Day 8: Integration
16. Read `06-architecture/patterns.md` — the COM bridge pattern
17. Build the COM worker thread prototype
18. Connect it to a minimal NiceGUI page
19. Verify: click a button in the browser → SAP transaction changes → status updates in the browser

### Day 9–10: First Feature
20. Pick the simplest real use case (e.g., "show current SAP screen info")
21. Implement it end-to-end through the full stack
22. Celebrate — the hardest part is behind you
